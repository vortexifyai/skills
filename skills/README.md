# Vortexify skills

These four skills work together as the Vortexify plugin:

- `vortexify-project`: project context, resource inspection, dependencies, and CLI workflows.
- `vortexify-connectors`: connector configuration, discovery, extraction, and syncs.
- `vortexify-apps`: React apps, project APIs, and agent conversations.
- `vortexify-app-design-patterns`: application layouts and interaction patterns.

See the [plugin README](../README.md) for installation and examples. Install the plugin as a whole so the skills and their shared references stay together.
